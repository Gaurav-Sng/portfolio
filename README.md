## Built With

- HTML5, CSS3 (custom properties, Grid/Flexbox, CSS animations)
- Vanilla JavaScript (IntersectionObserver for scroll reveal, no frameworks)
- Fonts: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts

No build tooling required — it's a single static `index.html` file.
